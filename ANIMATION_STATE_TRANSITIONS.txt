┌──────────────────────────────────────────────────────────────────────────┐
│ Priority 1: ACTION (Highest)                                             │
│   - ATTACKING, CASTING, BLOCKING, DODGING, CHANNELING, DEATH, USING_ITEM│
│   - Generally cannot be interrupted (except BLOCKING, CHANNELING)        │
│                                                                          │
│ Priority 2: LOCOMOTION                                                   │
│   - WALKING, RUNNING, JUMPING, FALLING, SWIMMING                        │

STATE TRANSITION RULES:
┌──────────────────────────────────────────────────────────────────────────┐
│ ALLOWED TRANSITIONS:                                                     │
│   ✓ Higher Priority → Lower Priority (always)                           │
│   ✓ Lower Priority → Higher Priority (always)                           │
│   ✓ Same Priority → Same Priority (if current is interruptible)         │
│   ✓ Any State → Death (highest priority override)                       │
│                                                                          │
│ BLOCKED TRANSITIONS:                                                     │
│   ✗ Action (non-interruptible) → Any State (must complete)              │
│   ✗ Action → Lower Priority (must complete or be interrupted)           │
└──────────────────────────────────────────────────────────────────────────┘

COMMON TRANSITION SEQUENCES:

1. BASIC COMBAT:
   IDLE (player presses attack) → [0.5s] → ATTACKING (0.6s animation)
   → [0.3s] → IDLE

2. WALKING TO ATTACK:
   WALKING (player attacks) → [0.5s] → ATTACKING (movement stops, 0.6s)
   → [0.3s] → IDLE → [0.2s] → WALKING

3. ATTACK COMBO (QUEUED):
   IDLE → [0.5s] → ATTACKING(1) (0.6s) → [0.1s] → ATTACKING(2) (0.6s)
   → [0.1s] → ATTACKING(3) (0.6s) → [0.3s] → IDLE

4. SPELL CASTING:
   IDLE (start cast) → [1.0s] → CASTING (1.0s animation) → [0.3s] → IDLE

5. CHANNELING WHILE MOVING:
   IDLE → [0.3s] → CHANNELING (loop) + WALKING (blended, can move)
   → (stop channel) → [0.3s] → WALKING

6. DEFENSIVE STANCE:
   WALKING → [0.3s] → BLOCKING (loop, can still move)
   → (release) → [0.3s] → WALKING

7. INTERRUPTED TRANSITION (ATTACK → BLOCK):
   WALKING → [0.5s] → ATTACKING (0.3s elapsed)
   → (try to block) → REJECTED (attack must complete)
   → ATTACKING continues → [0.3s] → IDLE → [0.3s] → BLOCKING

8. DEATH:
   ATTACKING (hit by fatal damage) → DEATH (1.5s) → (stays in death state)

ANIMATION QUEUEING:

  [Attack] → [Attack] → [Attack]
   Playing   Queued     Queued

  [Attack] → [Attack]
   Playing   Queued

  [Attack]
   Playing

  (return to IDLE or LOCOMOTION based on movement)

SPECIAL CASES:

✓ Walking while Blocking:
  BLOCKING state allows movement, so character can walk while blocking.
  Both animations blend together.

✓ Walking while Channeling:
  CHANNELING state allows movement, character can move while channeling.
  Both animations blend together.

✗ Walking while Attacking:
  ATTACKING does NOT allow movement, character is locked in place.
  Movement is blocked until attack completes.

✗ Attacking while Casting:
  Both are Priority 1 and non-interruptible.
  Second action is queued or rejected based on configuration.

✓ Death overrides everything:
  DEATH has implicit highest priority.
  Any state → DEATH when unconscious/dead.
